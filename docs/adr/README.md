# Architecture Decision Records

Significant design decisions, one per record, with the context and trade-offs
that produced them. Format follows
[Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions),
with the Decision Drivers and Considered Options sections from
[MADR](https://adr.github.io/madr/).

Accepted records are not edited. A changed decision gets a new record that
supersedes the old one.
